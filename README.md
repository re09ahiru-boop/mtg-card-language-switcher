# MTG Card Language Switcher

**MTGカードの日本語・英語を検索・比較する、Windows向けの非公式ファンツールです。**

> **現在：v1.0 公開準備中**  
> 権利・ライセンスの最終確認が完了するまで、アプリのダウンロードは公開していません。

## 主な機能

- **英語 ⇔ 日本語**：カード名から反対言語のカードを検索
- **画像OCR**：画像をドラッグ＆ドロップしてカード名を読み取り
- **ゲーム画面キャプチャ**：画面からカード名の領域を選んで検索
- **カード画像の比較**：元画像を左、検索結果を右に表示
- **学習補正**：以前の成功したカード名に基づき、OCRの誤認識を補正（成功を保証するものではありません）

## 対応環境・注意事項

- Windows 10 / 11（64bit）向け
- カード情報と画像の検索にはインターネット接続が必要です
- OCR精度は元画像に依存します。特に日本語名の振り仮名等を誤認識する場合があります
- 動作確認済みのPC以外については、動作の保証はありません
- 公開後、初回実行時にWindows SmartScreenの警告が表示される場合があります。入手元とハッシュを確認し、不明な実行ファイルは起動しないでください
